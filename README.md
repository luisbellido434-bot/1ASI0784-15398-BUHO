## Despliegue en GitHub Pages
1. Subir el contenido de este repositorio a la rama `main` en GitHub.
2. Ir a **Settings > Pages**.
3. En **Source**, seleccionar **Deploy from a branch**, elegir la rama `main` y carpeta `/ (root)`, y guardar.
